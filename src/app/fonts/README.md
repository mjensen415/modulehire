# Bundled fonts

Variable (`wght`) WOFF2 files for `next/font/local` in `src/app/layout.tsx`, built from the TTFs in
[google/fonts](https://github.com/google/fonts) with `pyftsubset` (`--layout-features='*' --no-hinting`),
keeping the Unicode ranges Google Fonts served: Latin, Latin Extended, Vietnamese and Cyrillic Extended,
plus Cyrillic and Greek for JetBrains Mono.
